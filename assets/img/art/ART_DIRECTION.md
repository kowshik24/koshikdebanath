# Art Direction — Technical Posts & Site Illustrations

Visual system for every illustration on this site. Matches `assets/css/design-system.css`
(DesignMD source of truth). Goal: every piece looks like it came from the same publication.

## 1. Rules

1. **One mechanism, not every detail.** Pick a single core tension — compression vs. fidelity,
   hidden structure vs. surface output, intervention/steering, signal vs. noise — and let one
   focal element carry it.
2. **House medium (locked).**
   | Role | Value |
   |---|---|
   | Ground | warm cream cotton paper `#FAF9F5` + fine grain |
   | Linework | charcoal ink `#141413` |
   | Primary accent | muted terracotta `#D97757` (deep: `#C6613F`) |
   | Secondary accents (max one per piece) | slate blue `#6A9BCC`, sage `#788C5D` |
   | Paper cut-outs | sand `#E3DACC` |
   | Pencil / guides | `#B0AEA5`, `#C6C4BA` |
3. **Structured geometry + organic imperfection.** Strict grid, matrix, ledger or axis, set against
   wobbly ink lines, torn paper edges, graphite hatching.
4. **Protect negative space.** Focal motif sits in the middle ~60%; the rest is open cream so it
   works in cards, headers and thumbnails without fighting headlines.
5. **No AI clichés.** No glowing neon brains, 3D glass cubes, floating holograms, sci-fi circuits,
   glossy gradients. No text, labels or numbers in the art.

Format: 16:10 (800×500), no border baked in (CSS adds the 1px `#C6C4BA` frame + 8px radius).

## 2. Prompt formula (for image generators)

```
[Core conceptual metaphor & focal action] + [Structural / technical motif]
+ [Handmade medium & surface texture] + [Color palette & composition constraints]
```

## 5. Iteration tips

- **Too literal / techy:** swap "neural network", "LLM", "vector", "database" for physical
  stand-ins — woven threads, grid tiles, stacked cards, ruled sheets.
- **Too busy:** cut secondary objects; add "generous empty cream background around a single central
  motif" so it reads at thumbnail and card size.
- **2–3 variations per post:** keep the prompt identical, vary only the focal metaphor. Each article
  gets its own identity without breaking the system.
